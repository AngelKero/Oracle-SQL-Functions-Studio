⚡ Módulo 1: Fundamentos de Funciones SQL

Funciones de Fila Única (Single-Row) vs. Funciones Múltiples (Multiple-Row)

Comprende el rol fundamental de las funciones en SQL, los dos grandes tipos de funciones y las características esenciales de las funciones de fila única.

1. ¿Qué es una Función SQL?

En Oracle SQL, una función es un programa almacenado que toma cero o más argumentos de entrada, realiza un cálculo o manipulación predefinida y devuelve un resultado. - Entrada (Input): Argumentos (arg 1, arg 2, literales, expresiones o nombres de columnas). - Proceso (Function): Realiza operaciones matemáticas, de texto, fechas o conversión de tipos de datos. - Salida (Output): Un valor resultante. 

[ Argumento 1, Argumento 2 ] ──▶ ┌────────────────────────┐ ──▶ [ Valor Resultante ]
                                  │  FUNCIÓN DE FILA ÚNICA │
[   Fila de la Tabla     ] ──▶ └────────────────────────┘

2. Dos Tipos de Funciones SQL

Oracle clasifica las funciones en dos categorías fundamentales: 1. Funciones de Fila Única (Single-Row Functions): - Operan sobre cada fila individual devuelta por la consulta. - Devuelven exactamente un resultado por cada fila. - Pueden modificar el tipo de dato devuelto. - Pueden anidarse a cualquier nivel de profundidad. - Aceptan columnas, expresiones o valores constantes como argumentos. 2. Funciones de Múltiples Filas (Multiple-Row / Group Functions): - Toman un conjunto de filas como entrada (un grupo) y devuelven un único resultado acumulado para todo el grupo (ejemplo: AVG, COUNT, MAX, MIN, SUM).
Regla de Oro del Examen Oracle

Una función de fila única SIEMPRE retorna un valor por cada fila procesada por la consulta. Si la consulta procesa 100 filas, la función se ejecuta 100 veces y produce 100 resultados.

3. Clasificación de Funciones de Fila Única

En este curso analizamos las cinco familias principales de funciones de fila única descritas en el estándar de Oracle: - 🔤 Funciones de Carácter: Aceptan caracteres como entrada y pueden devolver valores de caracteres o números. - 🔢 Funciones Numéricas: Aceptan entradas numéricas y devuelven valores numéricos. - 📅 Funciones de Fecha: Operan sobre valores de tipo DATE de Oracle. - 🔄 Funciones de Conversión: Convierten valores de un tipo de dato a otro (ej. fecha a texto, número a texto). - ⚙️ Funciones Generales y Condicionales: Manejo avanzado de valores nulos (NVL, COALESCE) y ramificación lógica (CASE, DECODE).

Práctica 3 - Reto 2: Cálculo de Meses y Años de Servicio
Intermedio

Para cada empleado del departamento 90, muestra su apellido (LAST_NAME), fecha de contratación (HIRE_DATE), el número de meses trabajados (MONTHS_WORKED) redondeado al entero más cercano con ROUND, y los años completos de servicio (YEARS_WORKED) truncados con TRUNC.

SELECT last_name, hire_date, 
       ROUND(MONTHS_BETWEEN(SYSDATE, hire_date)) AS MONTHS_WORKED,
       TRUNC(MONTHS_BETWEEN(SYSDATE, hire_date) / 12) AS YEARS_WORKED
FROM employees
WHERE department_id = 90
Práctica 3 - Reto 3: Búsqueda con Case Insensitive y Longitud
Intermedio

Genera un reporte que muestre el EMPLOYEE_ID, el nombre y apellido concatenados en una sola columna con CONCAT y separados por un espacio, y la longitud del apellido (LENGTH) para todos los empleados cuyo apellido comience con 'H' o 'h' (usa LOWER o UPPER).

SELECT employee_id, CONCAT(CONCAT(first_name, ' '), last_name) AS FULL_NAME, LENGTH(last_name) AS NAME_LEN
FROM employees
WHERE LOWER(SUBSTR(last_name, 1, 1)) = 'h'

SELECT last_name, LPAD(salary, 15, '*') AS SALARY_PAD

Práctica 3 - Reto 5: Compensación Total con NVL y Comisiones
Intermedio

Muestra el apellido (LAST_NAME), el salario mensual (SALARY), el porcentaje de comisión reemplazando nulos por 0 con NVL, y la compensación anual total calculada como (salary * 12) + (salary * 12 * commission_pct).

SELECT last_name, salary, NVL(commission_pct, 0) AS COMM_PCT,

FROM employees

Elimina caracteres iniciales, finales o de ambos extremos de una cadena.

REPLACE(text, search_string, [replacement_string])
Reemplaza cada aparición del texto de búsqueda por el texto de reemplazo.

Trunca el número a n posiciones decimales sin redondear.
Ej: TRUNC(45.923, 2) 45.92
MOD Numéricas
MOD(m, n)
Devuelve el resto o residuo de la división entera de m entre n.
Ej: MOD(1600, 300) 100

NVL2 Generales (Nulos)
NVL2(expr1, expr2, expr3)
Si expr1 NO es nulo retorna expr2; si expr1 ES nulo retorna expr3.
Ej: NVL2(commission_pct, 'SAL+COMM', 'SAL') 'SAL' o 'SAL+COMM'
NULLIF Generales (Nulos)
NULLIF(expr1, expr2)
Compara expr1 y expr2. Si son iguales devuelve NULL; si son diferentes devuelve expr1.
Ej: NULLIF(LENGTH(first_name), LENGTH(last_name)) NULL si longitudes coinciden
COALESCE Generales (Nulos)
COALESCE(expr1, expr2, ... expr_n)
Devuelve la primera expresión no nula de la lista. Tiene la ventaja de aceptar múltiples alternativas.
Ej: COALESCE(manager_id, commission_pct, -1) Primer valor no nulo
CASE Condicionales
CASE expr WHEN v1 THEN r1 [WHEN v2 THEN r2] [ELSE def] END
Expresión estándar ANSI SQL para lógica IF-THEN-ELSE en consultas.
Ej: CASE job_id WHEN 'IT_PROG' THEN 1.10*salary ELSE salary END Salario revisado
DECODE Condicionales
DECODE(col_or_expr, search1, result1, [search2, result2, ...], [default])
Función propietaria de Oracle para implementar lógica condicional IF-THEN-ELSE.
Ej: DECODE(job_id, 'IT_PROG', 1.10*salary, salary) Salario revisado
