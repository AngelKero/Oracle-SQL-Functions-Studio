# Tech Context: Oracle SQL Single-Row Functions Learning Platform

## Stack Tecnológico
- **Frontend Core**: HTML5 semántico, CSS3 moderno (Vanilla CSS con variables de diseño, glassmorphism, flexbox/grid moderno), JavaScript moderno (ES Modules, sin dependencias pesadas que ralenticen la carga).
- **Herramientas de Visualización**:
  - SVG dinámico y Canvas para diagramas de ejecución y árboles de funciones anidadas.
  - Tablas reactivas interactivas con paginación y ordenamiento.
- **Entorno de Ejecución**:
  - Navegador web estándar (Chrome, Safari, Firefox, Edge).
  - Cero dependencias complejas de backend: 100% cliente para máxima velocidad, portabilidad y disponibilidad inmediata sin necesidad de levantar contenedores de Oracle DB pesados.
- **Datos Embebidos**:
  - Tabla `EMPLOYEES` canónica del esquema HR de Oracle con registros reales (King, Kochhar, De Haan, Higgins, Ernst, Whalen, Lorentz, Mourgos, Rajs, Davies, Matos, Vargas, Russell, Partners, etc.).
  - Tabla `DUAL` con fila dummy estándar.
